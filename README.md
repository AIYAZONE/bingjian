# 冰鉴 · 七天共读

> 一天一篇，七天通读《冰鉴》。零依赖单文件阅读器。

《冰鉴》旧题清·曾国藩撰，共七篇，依次为神骨、刚柔、容貌、情态、须眉、声音、气色。全书以「一身精神具乎两目，一身骨相具乎面部」开篇，从静态的骨相到动态的情态，从先天的刚柔五行到后天的气色变化，构建了一套由内而外、由静而动、由本而末的观人体系。七篇虽短，义理精微，是中国传统相人术的纲领之作。

## 功能特性

### 阅读
- 目录导航 + 进度条，目录带日程日期，一键「跳到今日篇」
- URL `#ch-N` 直达定位，便于社群分享
- 双阅读模式：分页（一篇一页 / 键盘翻页）↔ 连续长页
- 手机优先、浅色仿书版式；PC 端左侧固定目录栏
- 原文按义理分段，每篇 3–5 段，阅读不累

### 每篇内容（七标签）
- **译文**：逐句「原文 ↔ 今译」对照，共 156 句
- **注释**：生僻字注音（97 字）+ 通假/异读虚线提示（6 条）
- **串讲**：义理疏通 + 经证链（引《孟子》《论语》《人物志》《黄帝内经》《世说新语》等）
- **解读**：生活启发——落到日用常行的提醒
- **导读**：本篇要旨总结
- **省察**：篇末自省提问 +「我的践行笔记」

## 技术说明
